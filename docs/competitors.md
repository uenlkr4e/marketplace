**Pricing pattern:** every returns app caps the free plan by requests per month (3–20); paid plans run from about TL125 to TL4000 a month.

**Only Parcelback has:** order and shipment tracking on the same page, a logged-in member's order list, and everything free and unlimited.

## Features to add

### High: most competitors have them
1. **Exchanges.** Another size or colour instead of a refund; a linked replacement order, with a payment link for any price difference. (7 apps)
2. **Store credit.** A gift card or single-use discount code instead of a refund, optionally with a bonus. (5 apps)
3. **Restock per item.** Choose which returned items go back into stock. We restock all or nothing.
4. **Return instructions and label link.** Return address and instructions in Settings, shown once a return is approved; the merchant can attach a label link and the return parcel's tracking.
5. **Standalone withdrawal button for the footer.**

### Medium: Pro plan material
6. Restocking fee (% or flat) and who pays return shipping.
7. Auto-approve rules.
8. Panel on the Wix order page (dashboard plugin slot), including starting a return for phone or email requests.
9. Reminders before the withdrawal refund deadline.
10. Return analytics: return rate, top reasons, cost per reason.
11. Widget theme options: colours, font, corners.

### EU compliance edge
12. All 24 official EU languages for the withdrawal button and form (we have 7).
13. Withdrawal for Bookings and Events orders.
14. Team copies of each withdrawal and a monthly summary.
15. Legal-guarantee notice block for product pages.

### Nice to have
16. Aria (Wix AI assistant) support through the app tools extension.
17. Bookmarkable status link per request.
18. Reason per item.
19. Edit and reopen a request, with a dated history.

**Suggested order:** 3 and 4 (small), then 2 and 1. Then a request cap as the free-plan limit, with 6–10 in Pro.
